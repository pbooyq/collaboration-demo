# Collaboration Demo Project

This project is used to practice Git and GitHub collaboration workflows.

## How to contribute
- Open an issue
- Create a branch
- Submit a pull request

## Features

- Issue-based task management
- Feature development using separate branches
- Pull request review workflow
- Automated CI checks with GitHub Actions
- Contributors should verify that all CI checks have passed before merging a pull request.

## How to contribute

1. Open an issue describing the proposed change.
2. Create a separate branch for the issue.
3. Make only the changes related to that issue.
4. Commit the changes using a clear commit message.
5. Push the branch to GitHub.
6. Submit a pull request and link the related issue.
7. Wait for the review and address requested changes.
8. Verify that all CI checks have passed before merging.
